# Febspot

Modern social network to share moments with friends.

## Features

- Friends and groups
- Search and notifications
- Profiles

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/spot-echo-generator.git
cd spot-echo-generator
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
